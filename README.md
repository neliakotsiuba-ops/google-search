# 🔍 Google Search Clone

A front-end clone of Google Search built with pure HTML and CSS.

## ✨ Features

- Google Search main page with search form
- Image Search page
- Advanced Search page with multiple filter options
- Functional — searches redirect to real Google results

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
